Lagos Bites

A lot of restaurants in Lagos take orders over WhatsApp and phone calls. Orders get lost and nobody's quite sure who has paid. Lagos Bites is a small ordering system for that: customers pay online with Paystack, and the restaurant sees every order in one place.

The bit I'm proudest of is the payment flow. The server ignores whatever price the browser sends, works it out again from the database, and checks with Paystack before marking anything paid. You can't fake an order.

  • Admin dashboard with JWT login, order search and revenue numbers
  • Zod validation on every request
  • React and Express on MongoDB, hosted on Netlify and Render

Funds Accountability Tracker

The idea is simple: if a group pools money for something, everyone should be able to see where it went. You record what comes in and what goes out, the balance keeps itself up to date, and you can send a read-only link to anyone who needs to keep an eye on it.

Most of the work went into the backend: JWT auth, API keys, and making sure a shared link can look but never touch.

  • Wallets, income and expenses, full transaction history
  • Revocable read-only share links
  • API docs and a security write-up in the repo
